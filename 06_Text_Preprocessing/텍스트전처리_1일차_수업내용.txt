3. 텍스트 전처리 개념과 과정

[텍스트 수집] → [클렌징] → [소문자 변환] → [토큰화] → [불용어 제거] → [표제어 추출] → [추가 전처리]

1) 텍스트 수집
  :  웹사이트, 파일(txt, csv, pdf), 데이터베이스 등에서 텍스트 수집
2) 클렌징(Cleansing) 
 : 특수문자, 이모지, 공백, 태그(HTML) 같은 불필요한 것 제거
   예: Hello!!! :) <p>Hi there</p> → Hello Hi there
3) 소문자 변환(Lowercasing)
  : 대소문자를 통일시켜서 분석할 때 중복 방지
   예: Apple, apple → apple
4) 토큰화(Tokenization)
  : 문장을 단어(또는 문장) 단위로 나누는 것
   예: "I love AI." → ["I", "love", "AI"]
5) 불용어 제거(Stopwords Removal)
   "the", "is", "and"처럼 의미 없는 단어 제거
   (한국어라면 "은", "는", "이", "가" 같은 조사 제거)
6) 표제어 추출(Lemmatization) 또는 어간 추출(Stemming)   
 :  단어의 원형을 찾기
   예: running → run, better → good
7) 추가 전처리 작업
 - 품사 태깅 (POS tagging)
   : 단어에 품사(명사, 동사 등)를 붙임
 - NER (Named Entity Recognition)
   : 고유명사(사람, 장소, 기관 등)를 추출
 - 필요하면 한글자 제거, 길이 제한, 숫자 제거, 띄어쓰기 교정 등 추가 전처리

4. 정규표현식
 : 특정한 규칙(패턴)을 가진 문자열을 찾거나 조작하기 위한 특수한 언어

활용 예. 텍스트에서 이메일 주소만 찾기
    숫자만 추출하기
    특정 형식의 문장을 감지하기
    불필요한 공백, 특수문자 지우기

1) 모듈
  import re

2) 문자 매칭

패턴	의미	예시 매칭
.	임의의 한 문자	a, 1, #
^	문자열의 시작	^Hello → "Hello world"
$	문자열의 끝	world$ → "Hello world"
*	앞 문자가 0개 이상 반복	lo* → "looong", "log"
+	앞 문자가 1개 이상 반복	lo+ → "looong", "log"
?	앞 문자가 0개 또는 1개	lo?g → "log", "lg"
{n}	정확히 n번 반복	a{3} → "aaa"
{n,m}	n~m번 반복	a{2,4} → "aa", "aaa", "aaaa"

3) 문자 집합

패턴	의미	예시 매칭
[abc]	a 또는 b 또는 c 중 하나	"a", "b", "c"
[^abc]	a, b, c 제외한 문자	"d", "e", "1"
[a-z]	소문자 알파벳 a~z	"d", "m"
[A-Z]	대문자 알파벳 A~Z	"D", "M"
[0-9]	숫자 0~9	"1", "8"

4) 자주 쓰는 특수 그룹

패턴	의미	예시 매칭
\d	숫자 (0-9)	"1", "7"
\D	숫자가 아닌 문자	"a", "#"
\w	단어 문자 (알파벳 + 숫자 + _)	"a", "Z", "7", "_"
\W	단어 문자가 아닌 것	"!", " "
\s	공백 문자 (space, tab, newline)	" ", \t, \n
\S	공백이 아닌 문자	"a", "9"


5) 그룹핑과 선택

패턴	의미	예시
(abc)	그룹핑	"abc"를 하나의 그룹으로 취급
`a	b`	a 또는 b

6. 정규화
1) 정제(cleaning) 
  - 갖고 있는 코퍼스로부터 노이즈 데이터를 제거
  - 특수문자 제거, 공백 제거, HTML 태그 제거, 이모지 제거 등

2) 정규화(normalization)
  - 표현 방법이 다른 단어들을 통합시켜서 같은 단어로 만들어줌
  - 대소문자 통일, 축약어 풀기, 철자 교정, 중복 문자 줄이기 등
