1. 모듈(module)과 패키지(package)

1) 모듈
# 모듈 : 하나의 파이썬 파일 .py
    => 하나의 모듈
  변수, 함수, 클래스, 상수 등을 논리적으로 묶은 코드 파일
  - 코드 재사용, 유지보수 용이, 가독성 향상

# 모듈 작성 : .py로 작성
# 모듈 이용 : import를 사용

# 모듈 import 방식
 방식1. import 모듈명 -> 모듈에 있는 모든 대상을 다 불러옴
import my_math_
print(my_math_.add(3,4))

 방식2. 별칭 사용 -> 모듈 이름이 긴 경우 줄여서 별명으로 사용
    모듈에 있는 모든 대상을 불러옴
import my_math_ as mm
print(mm.mul(2,3))

방식3. 특정한 대상(함수)만 불러옴  : from 모듈명 import 함수명
#  - 모듈이름을 사용하지 않고 불러온 함수이름만 사용
#  - 실무에서 가장 많이 사용
#  - 모듈에 정의된 많은 함수들 중에 필요한 것만 사용
from my_math_ import add, sub
print(add(10,4)) 


2) 패키지(package)
  - 여러 모듈을 폴더 구조로 묶은 것
  - 관련된 모듈들을 디렉터리(폴더) 단위로 구조화
  - 대규모 프로젝트 구조 관리에 도움
  
예.
my_pakage 폴더
 |-- __init__.py   => 해당 폴더를 패키지로 인식 (내용이 없는 모듈)
 |-- my_math.py
 |-- show_info.py
 |-- my_string.py

# 패키지 import
# from 패키지명 import 모듈명
# from 패키지명.모듈명 import 함수

from my_package.my_math import add
from my_package import my_string

print(add(3,10))
print(my_string.reverse('안녕하세요'))

2. 예외처리(exception)
- https://docs.python.org/ko/3/tutorial/errors.html
- https://docs.python.org/ko/3/library/exceptions.html

1) 예외(Exception) :
    실행 중 발생하는 오류

- 오류(Error)
    - 문법적 오류(Syntax Error) : 파이썬 문법을 잘못 사용하는 경우 발생하는 오류
        키워드 잘못 입력
        if, for, def 등에서 :을 빼거나
        블록을 위한 들여쓰기가 일정하지 않거나, 잘못 들여쓰거나
        문법 오류 발생 시 VSCode에서 빨간 밑줄이 그어짐
    - 실행시간에 잘못된 메모리 접근 오류
    - 논리적 오류 : 예상과 다른 결과가 나오는 경우
        알고리즘에 문제
        변수 초기화하지 않고 변경시키려 할 때
        자료형이 틀릴 때
        인덱싱/슬라이싱을 잘 못 사용
    - 사용자의 잘못된 입력 오류

- 오류가 발생하면 프로그램은 중단되고 에러 메시지 출력

2) 발생되는 에러의 예
    - SyntaxError : 문법오류
    - TypeError : 연산을 수행할 때 연산에 맞지 않는 자료형을 사용하는 경우 발생
    - ValueError : 값을 잘못지정
                문자열 포맷 서식에서 잘못된 값으로 지정한 경우
                print('%d%' % c)
    - NameError : 변수이름이 없는 경우, 변수가 정의되지 않은 경우 사용할 때 발생
    - IndexError : 리스트,문자열,튜플과 같은 시퀀스형 데이터에서 인덱스 위치를 잘못지정한 경우
    - KeyError : 키값을 설정하지 않거나 잘못된 키값 지정하는 경우
    - ZeroDivisionError : 0으로 나누는 경우
    - FileNotFoundError : 파일이나 경로가 없는 경우
    - UnboundLocalError : 지역변수와 관련된 오류
            += 연산을 사용하여 변수에 값을 할당할 때 초기값이 지정된 후 사용하지 않고
            바로 사용한 경우
            a += 10
    - ModuleNotFoundError : 모듈을 임포트할 때 모듈이름을 지정하지 않거나
            잘못된 이름의 모듈을 지정
    - OSError  : 파일이나 폴더의 경로를 잘못 지정해서 발생 
            백슬래스(\)를 두번사용하지 않고 한 번만 사용한 경우

- 파이썬의 예외(Exception)
    Exception 클래스를 상속받은 다양한 오류를 처리하기 위한 예외 클래스들이 계층적으로 구성되어 있음
    https://docs.python.org/3/library/exceptions.html#exception-hierarchy

3) 예외 처리 구문 try~except문
- 예외 처리
    - 오류 발생 시 프로그램을 중단하지 않고 
      오류(예외)가 발생할 지점에 예외를 피하거나 다른 수행을 함으로써 정상 실행이 되도록 하는 방식

    try:
        예외 발생 가능 문장
    except:
        예외 처리
    else:
        예외가 발생하지 않는 경우 수행 문장
    finally:
        예외발생유무와 상관없이 항상 실행되는 문장

    else ~ finally는 생략가능

try:
    x = int(input("Please enter a number: "))
except ValueError:
    pass
else:
    print(x)
finally:
    print('종료')


# 예외 일으키기 : raise 문 사용

try:

finally:
