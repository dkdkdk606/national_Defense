2. 문자열(text)

3) 문자열의 특징
   - 순서를 갖는 시퀀스(sequence) 자료형
   - 각 요소를 인덱스(index)를 사용하여 참조
   - 가장 많이 사용하는 자료형

4) 문자열의 연산 (시퀀스형 자료에 공통된 연산)
    * 시퀀스형 자료 : 문자열, 리스트, 튜플
    - 인덱싱(indexing) : 문자열변수명[k] => k번 위치의 값을 가져옴
    - 슬라이싱(slicing) : 문자열변수명[start:stop+1:step]
                   => start부터 stop까지의 step 간격의 인덱스의 문자만 가져옴
    - 연결하기(concatenate) : + 연산자 => 두 문자열을 하나의 문자열로 연결
    - 반복하기 : * 연산자 => 여러 번 반복해서 하나의 문자열로 결합
    - 멤버검사 : in 연산자 => 어떤 문자가 있는지 검사 True / False
    - 길이정보 : len() 함수 => 문자열의 길이

5) 문자열 서식 지정(포맷)
: 문자열 포맷팅(formatting) => 포맷서식

① 포맷코드 : %포맷
  '     %s ' % 변수  : 문자열
  '     %d ' % 변수  : 정수
  '     %f ' % 변수  : 실수
  '     %c ' % 변수  : 문자

② format() 함수
 format(변수, 서식)
 format(12300, ',')  => '12,300'

③  문자열.format()
  '문자열 {위치인덱스} '.format(변수)
  '문자열 {변수} '.format(변수=값)
  '문자열 {위치인데스:포맷코드} '.format(변수)

result = '이름 : {0} , 주소 : {1}, 총점 : {2}, 평균 : {3}'.format(name, addr, total, avg)
result = '이름:{name} , 나이:{age}살'.format(name='짱구', age=10)
pi = 3.141592
result = '원주율은 {0:.2f}'.format(pi)
result = '원주율은 {0:10.2f}'.format(pi)

# 정렬 서깃 문자 사용 : 
  왼쪽 정렬 : < 
  오른쪽 정렬 :  >
  가운데 정렬 :   ^print('-'*20)

text = '파이썬'
print('{}'.format(text))
print('{0}'.format(text))
print('{0:<10}'.format(text))   # 전체 10자리 왼쪽 정렬
print('{0:>10}'.format(text))   # 전체 10자리 오른쪽 정렬
print('{0:^10}'.format(text))   # 전체 10자리 가운데 정렬
print('{0:-^10}'.format(text))   # 공백문자 지정
print('-'*20)
