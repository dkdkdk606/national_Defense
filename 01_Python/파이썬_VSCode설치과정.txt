✅ 파이썬 설치 과정

1단게. python.org 사이트에서 3.14.6 다운로드
2단계. 다운로드 받은 exe 파일 실행
3단계. 아래의 옵션 모두 체크하고,  Install Now 클릭
    Add python.exe to PATH
    Use admin privileges when installing py.exe
4단계. 디바이스 변경 허용 [예] 클릭
5단계. 설치 진행
6단계. 설치 성공 -> close 클릭


✅  VS Code 설치
1단계. VS Code Community 설치파일 다운로드 (Windows 버전)
2단계. 설치 파일 실행
3단계. 사용권계약 [동의합니다] 선택 후 [다음] 버튼 클릭
4단계. 설치 위치 선택 :  [다음] 버튼 클릭
5단계. 시작 메뉴 폴더 선택 : [다음] 버튼 클릭
6단계. 추가 작업 선택 : [다음] 버튼 클릭
7단계. 설치 준비 완료 : [설치] 버튼 클릭
8단계. 설치 진행
9단계. 설치 마법사 완료 : [종료] 버튼 클릭

✅  VS Code 실행 후 Extension 설치
1. 왼쪽 사이드 상단의 다섯번째 Extension 아이콘 클릭
2. 검색에 Python 입력
3. 검색된 확장팩들중 처음 나오는 Microsoft의 Python애서  install 버튼 클릭하여 설치

✅  Open Project Folder 추가
extension 설치 후 나타나는 Welcome 페이지에 [Open Project Folder] 설정하도록 나타난 경우
[Open Project Folder] 버튼 클릭하고
D: 드라이브에 작성한 Workspaces폴더 아래 01_Python 폴더를 선택한다
(폴더가 없으면 D드라이브나 C드라이브 루트에 Workspaces
 폴더 생성 후 그 아래 01_Python 폴더를 생성한 후 선택한다)
