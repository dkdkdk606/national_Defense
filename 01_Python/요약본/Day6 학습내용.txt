1. 튜플(tuple)
1) 특징
- 읽기전용 데이터: 삽입, 삭제, 수정 불가
- 리스트와 유사한 시퀀스 자료형
- 튜플의 생성 : () 또는 tuple()함수 사용
- 튜플의 요소들은 인덱스([])로 구분

2) 생성
 :  ( ) 또는 tuple() 함수, 콤마(,) 구분
   변수명 = (1,)  1,
   변수명 = 1,2,3

- 튜플안에 다양한 자료 포함

3) 연산
- 인덱스를 통해 요소 접근, 그러나 요소값 변경 불가
- 복수 개 요소 치환
   x,y = 1,2
- 패킹과 언패킹
  x = (1,2,3)
 a,b,c = x
 a, *b = x

- 요소 접근(인덱싱)
t = 'apple', 'banana', 'berry', 'melon'
for i in range(len(t)):
    print(t[i])

- 슬라이싱
print(t[1:])
print(t[::2])
print(t[::-1])

- 연결: 더하기 연산(+)
t1 = (3,4,5)
t2 = 10,11,1
t3 = t1 + t2
print(t3)

- 반복 : 곱하기 연산(*)
t1 = ('Hi',)
print(t1, type(t1))
print(t1 * 10)

- 튜플의 길이 : len()
print(len(t1*10))

- 튜플의 멤버 확인 : in / not in
t = 'apple', 'banana', 'berry', 'melon'
print('kiwi' in t)
print('kiwi' not in t)
print('berry' in t)

4) 튜플의 메서드
-  요소의 위치 : index()
print(t.index('a'))
print(t.index('b'))
print(t.index('a', 2))
print(t.index('a', 1, 3))
# print(t.index('a', 3, ))  # 찾는 요소가 없는 경우 오류 발생(ValueError)

- 일치하는 요소의 수 : count()

5) 튜플의 실무 활용 예
- 변경되면 안되는 데이터 저장 : 안정성 보장
    : GPS 좌표, RGB 색상정보, ...
-  여러 값을 한 번에 변환    : 함수의 반환값
-  딕셔너리의 키 값으로 사용     : immutable
    예. { (120, 80) : 'Tank', }
- 데이터베이스 조회 결과  : 한 행(row) 표현
- 여러 변수 동시 할당(언패킹) : 코드 간결하게 
-  AI/데이터 분석 :  Shape, Size 정보


2. 딕셔너리(dictionary)
1) 특징
- 키와 값으로 구성된 매핑 데이터(hashable dataset)
- 집합적자료로 저장 순서가 없음
- 인덱스가 아닌 키로 요소 접근 : 딕셔너리변수[키]
- 생성 : {키:값,}, dict(), {}
- 키값은 숫자, 문자 모두 가능하며 유일한 값
- 리스트와 같이 자주 사용되는 데이터구조
- 데이터 분석, AI, 웹, API개발 등에 실무에 많이 활용되는 구조

2) 키(key)와 값(value)의 쌍으로 이루어진 구조
   - 형식 : { 키1:값1, 키2:값2, ... }
   - 중괄호 {}로 묶어 구성
   - 키 : 중복 불가, 변경불가한 데이터를 사용(정수, 실수, 문자열, 튜플)
   - 값 : 어떤 데이터 다 가능(정수, 실수, 논리, 문자열, 리스트, 튜플 등)
   - key:value 한 쌍을 item이라고 부름
   - item은 쉼표(,)로 구분
   - 다른 프로그래밍 언어에서는 해시(hash), 연관배열(associative array)이라 부름

3) 키 값으로 접근(인덱스 접근 불가)

4) 딕셔너리 뷰(view) : 딕셔너리 요소들을 동적으로 볼 수 있는 객체
	keys() : key에 대한 딕셔너리 뷰 반환
	values() : value에 대한 딕셔너리 뷰 반환
	items() : 항목(key:value)들의 딕셔너리 뷰 반환

5) 딕셔너리 주요 메소드
- get(키[, x]) : 지정한 키의 값을 반환 (키가 없으면 x를 반환)
- setdefault(키[, x]) : get() 메서드와 같은 역할, 
                        키에 해당하는 값이 없으면 그 값을 설정
- copy() : 딕셔너리 내용을 새로운 딕셔너리에 복사
            새딕셔너리 = 딕셔너리.copy()
- update() : 딕셔너리b의 모든 항목을 딕셔너리a에 갱신
            딕셔너리a.update(딕셔너리b)
- pop(키) : 키 항목의 값을 반환하고 딕셔너리에서 제거
- popitem() : (키,값) 튜플 항목을 반환하고 딕셔너리에서 제거
- clear() : 딕셔너리의 모든 항목을 삭제


3. 세트(set)
- 순서가 없으며, 동일한 요소가 중복될 수 없음
- 인덱스 사용 불가
- 요소 추가, 삭제 가능
- 리스트를 요소로 가질 수 없음
- 딕셔너리의 키값을 모아놓은 자료구조와 같음
- 생성 : set(), {}안에 직접자료지정
- 세트 메소드
 	add(), update()
	clear(), discard(), pop(), remove()
	intersection(), union(), difference()

4. 컴프리헨션
리스트 컴프리헨션 : 변수명 = [수식 for 변수 in 반복대상 if 조건식]
세트 컴프리헨션 : 변수명 = {수식 for 변수 in 반복대상 if 조건식}
딕셔너리 컴프리헨션 : 변수명 = {키:값 for 변수 in 반복대상 if 조건식}
