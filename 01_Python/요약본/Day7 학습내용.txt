2. 함수의 반환값 
- 반환값(return value) : 함수가 특정 기능을 수행하고 돌려주는 결과 값
- return 문 사용
- return문 사용하지 않은 경우 함수는 반환값이 None
- 함수의 반환값 데이터 형식은 모든 자료형 가능
    : 숫자, 논리, 문자열, 리스트, 튜플, 딕셔너리 등
- 함수의 반환값은 변수로 저장
    변수 = 함수명()


3. 함수의 매개변수(parameter) 
    함수의 입력값, 0개 이상
    하나의 값, 리스트, 딕셔너리 등 모두 가능

    - 매개변수(parameter) : 함수에 전달되는 값을 받는(저장) 변수

    - 인수(argument) : 함수에 실제로 전달되는 값
                함수 호출 시 사용되는 입력값

3) 위치인수와 키워드인수
  - 위치인수(positional argument) 
    : 정의된 함수의 매개변수 위치와 같은 위치의 인수가 전달

  - 키워드인수(keyword argument)
    : 매개변수이름에 값을 지정하는 형식으로 사용
       매개변수이름 = 값
      - 인수들 앞에 키워드(매개변수)를 두어서 인수를 구별
      - 인수의 위치가 매개변수의 위치와 달라도 됨

 - 키워드인수(디폴트매개변수)는 위치인수 뒤쪽에

# 위치인수와 키워드 인수를 함께 사용할 수 있으나,
# 위치인수를 키워드 인수보다 앞에 두어야 함(디폴트 매개변수)

# print(sub(b=10, 5))   # 10 -> b, 5 -> a
# SyntaxError: positional argument follows keyword argument

4. 지역변수와 전역변수
  지역변수(local variable) : 함수 내부에서의 변수
  전역변수 : 함수 밖에서 전역적으로 사용가능한 변수
  함수내부에서 전역변수를 사용할 경우 global 키워드로 선언

- 리스트를 함수의 인수로 사용할 경우
  : 인수로 전달된 리스트가 주소를 참조하므로 함수 내부에서 수정가능함

# local, nonlocal, global 차이
 - 함수 외부, 내부 또는 중첩함수에서 사용되는 동일한 이름의 변수들에 대한 사용 범위 구분

# nonlocal 키워드
 - 함수 내부에서 선언된 내부 함수(inner function)의 변수 사용 범위를 local에서 nonlocal로 지정
 - 중첩 함수 내에서 비지역 변수를 대상으로 사용

def func():
    global a
    a = 10
    def inner_func():
        a = 20
        print('inner_func():', a)
    inner_func()
    print('func():', a)

def func():
    a = 10
    def inner_func():
        nonlocal a
        a = 20
        print('inner_func():', a)
    inner_func()
    print('func():', a)

7. 람다함수
- 익명의 함수(이름없는 함수)로 한줄로 작성되는 함수
- 일회성으로 사용하는 작은 함수를 만들때 편리함
- return 문을 사용하지 않음
- 람다 함수의 몸체(body)는 문장이 아닌 하나의 식이다

- 람다 표현식 : 
    lambda 매개변수들 : 반환할 식
    변수명 = lambda 매개변수들 : 반환할 식
    (lambda 매개변수들 : 반환할 식)(인수들)

- 람다 함수는 함수 참조를 반환
- 변수로 람다 함수객체를 받아서 함수 호출을 할 수 있다

- 람다 함수 사용 목적
  : 함수의 인수 부분에서 간단하게 함수를 생성하여 사용하기 위해서
  - 코드 간결화
  - 일회성 함수
  - 함수형 프로그래밍에 사용하는 함수들과 결합 : map(), filter(), sorted()...
  - 가독성 개선 : 의미없는 함수 선언 제거

# 람다함수 매개변수(인수)에 기본값 설정할 수 있음
hap = lambda x, y: x+y
print(hap(100,30))

# 람다 표현식을 변수에 할당하지 않고 그 자체를 호출
print((lambda x=10, y=10: x+y)())
print((lambda x=10, y=10: x+y)(20,40))

# 람타 표현식 밖에 있는 변수 사용 가능
y = 200
print((lambda x: x+y)(1000))
