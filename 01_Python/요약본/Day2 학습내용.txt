1. 문자열 포맷팅(formatting) => 포맷서식
① %포맷
  '     %s ' % 변수  : 문자열
  '     %d ' % 변수  : 정수
  '     %f ' % 변수  : 실수
  '     %c ' % 변수  : 문자

② format() 함수
 format(변수, 서식)
 format(12300, ',')  => '12,300'

③  '  {0:f} {1:s} '.format( , )

④ f-string : f'{name:s} {age:5d} '

2. etc
주석 처리 : #, ''' '''', """ """
여러줄 로된 한문장 표현 : \
print(' '\
  ' ')  -> 한 줄의 문자열로 출력
escape 문자 : \\,  \n, \t, \', \"

3. 자료형
데이터표현 : bit < byte <
진법변환 : bin(), oct(), hex()
파이썬 내장 자료형 : int, float, comple, bool, str, list, dict, tuple, set
자료형 변환 : str(), int( , base=), float()
input(문자열) -> 키보드로 입력한 값을 문자열로 반환

4. 연산자
산술연산자 : + - * /  //  %  **
비트연산자 : & | ^ ~ << >>
관계연산자 : == != < >  <= >=
대입연산자 : += -= *= /= **= %= //=
논리연산자 : and  or  not

연산자 우선순위 : 
 1순위 : () [] {} 
 2순위 : **
 3순위 : +3 -4 : 단항연산자
 4순위 : 산술연산자 (* / % //  ,  + - )
 5순위 : 비트연산자 ( >>  <<  , & , ^, |)
 6순위 : 관계연산자 (< > <= >= , == !=)
 7순위 : 대입연산자 
 8순위 : 논리연산자 (not, and, or)
