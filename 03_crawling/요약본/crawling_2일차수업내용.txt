3) select() 메서드
- CSS 문법을 사용해 HTML 요소(element)를 선택하는 메서드
- find() / find_all() 보다 복잡한 HTML 구조를 간결하게 표현할 수 있는 장점
- 조건에 맞는 모든 요소를 리스트로 반환
- CSS Selector를 사용

 - 형식 : soup객체.select(선택자)
 - 리스트로 반환
    예. soup.select('#mainMenuBox')
      soup.select('a[href]')
      soup.select('.box')

[선택자] 
|선택방법		|CSS Selector|예	|
------------------------------------------------
|태그			|`태그명`	|div|
|class			|`.클래스명`	|.product|
|id			|`#아이디`	|#content|
|태그+class		|`태그.클래스`|div.product|
|하위요소(자손)	|`A B`		|ul a  <br> .product .name|
|직계자식		|`A>B`		|ul>li|
|여러 요소		|`A,B`		|h1, h2|
|속성|`[속성]`		|[href]		|
|속성값|`[속성=값]`	|[type='text']	|
|n번째 요소		|`:nth-child()`	|:nth-child(2)|

2. 정적페이지 크롤링 과정
 1) 모듈 임포트
   import requests
   from urllib.request import urlopen
   from bs4 import BeautifulSoup

2) 웹 크롤링 단계
단계1. 웹페이지 분석(파악) : 수집대상의 html 구조

단계2. 페이지 접근(요청)
  html = requests.get(url).text
또는
  html = urllib.request.urlopen(url).read()
  
단계3. 파싱(parsing): 추출
  soup = BeautifulSoup(html, 'html.parser')
  soup.find(),   soup.find_all(), ,soup.select() 이용한 파싱
