3. 웹크롤링 개요
- 크롤링 : 프로그램을 이용해서 자동으로 다양한 페이지에서 포괄적으로 데이터를 수집
- 크롤러 : 수집 프로그램
- 스크래핑 : 특정 페이지에서 필요한 정보 추출
- robots.txt : 크롤링 규칙 명시한 페이지(allow / disallow)


4. 웹 크롤링 단계

단계1. 웹페이지 분석(파악) : 수집대상의 html 구조
	태그 -> element
	속성 : a['href'] 
	선택자  : class, id

단계2. 페이지 접근(요청)
 - url 접속 연결 -> 결과 가져옴
 - 사용 모듈 : requests, urllib.request

 requests.get(url, verify= False, 
	      headers = {'user-agents':' '})  
   - SSL Certification Error 발생 시 verify=False 설정
   - 봇으로 인식하여 거절할 경우 User-agents를 지정
     user-agents : '브라우저 버전....  '

 response = requests.get(url)
 html = response.text
또는
 html = urllib.request.urlopen(url).read()
  
단계3. 파싱(parsing): 추출
 - BeautifulSoup 패키지 이용
 - BeautifulSoup 패키지 설치
   !pip install beautifulsoup4
 - BeautifulSoup 패키지 임포트
    from bs4 import BeautifulSoup
 - BeautifulSoup 객체 생성
   soup = BeautifulSoup(html, 'html.parser')
 - BeautifulSoup 객체의 find(), find_all(), select()를 이용한 파싱


5. 사용 모듈
 import requests
 from urllib.request import urlopen
 from bs4 import BeautifulSoup


6. BeautifulSoup의 파싱을 위한 속성과 메소드들
 - soup.prettify() : 출력

1) find(), find_all() 
 - soup객체.find(태그명, 속성) : 제일 첫번째 태그 반환
 - soup객체.find_all(태그명, 속성) : 리스트로 반환

2) 태그명으로 찾기 : 
 - 형식 : soup객체.태그명 (결과는 제일 첫번째 것만 반환)
     예. soup.head, soup.p

3) 부모,형제,자손 태그 찾기
     soup객체.태그명.contents
     soup객체.태그명.children
     soup객체.태그명.parent
     soup객체.태그명.parents
     soup객체.태그명.next_sibling
     soup객체.태그명.next_siblings
     soup객체.태그명.previous_sibling
     soup객체.태그명.previous_siblings
     soup객체.태그명.previous_sibling
    soup객체.find_all_next()
    soup객체.find_next()
    soup객체.find_all_previous()
    soup객체.find_previous()

3) select() 메서드
 - 형식 : soup객체.select(선택자)
 - 리스트로 반환
    예. soup.select('#mainMenuBox')
      soup.select('a[href]')
      soup.select('.box')
