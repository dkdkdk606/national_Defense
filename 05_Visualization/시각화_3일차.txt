folium을 이용한 지도시각화

1. 지도 객체 생성 

1)  foilum.Map( )
: 지도 객체 인수들

인수 이름 : 기본값 : 설명
-------------------------------
location :	 [0, 0] : 지도 중심 좌표를 지정하는 (위도, 경도) 리스트나 튜플.
width :	 	 '100%' : 지도의 가로 크기. (px, %, 등 가능)
height :	 '100%' : 지도의 세로 크기. (px, %, 등 가능)
zoom_start :	 10 : 시작할 때의 줌 레벨 (숫자가 클수록 확대)
control_scale : False : True면 지도에 거리 축척(스케일 바)을 표시
tiles :		 'OpenStreetMap' : 지도 배경 타일 스타일. 
			(예: "Stamen Terrain", "CartoDB positron", "Stamen Toner" 등)
attr : 		 None : 사용자 지정 타일 서버를 쓸 때 출처 표시 문구.
min_zoom :	 0 : 허용되는 최소 줌 레벨
max_zoom : 	 18 : 허용되는 최대 줌 레벨
max_bounds :  False : True면 사용자가 지도를 중심 경계밖으로 스크롤할 수 없음.
crs :		 'EPSG3857' : 좌표계 설정. (주로 'EPSG3857', 'EPSG4326' 사용)
prefer_canvas : False : 성능 향상을 위해 캔버스 렌더링을 우선 사용할지 여부
no_touch : False : 터치 이벤트를 막을지 여부
disable_3d : False : 3D 파노라마와 같은 효과를 비활성화할지 여부

    geo_prpty = [dong['properties'] for dong in geo_json['features']]

7. 단계 구분도(Choropleth Map)

1) 단계 구분도란?
- 행정구역 등과 같이 지도상의 어떤 경계로 구분된 지도 영역에 색을 칠하거나 음영 등을 넣어 정보를 나타낸 지도
데이터를 지도 그림에 반영시켜서 전달하는 그래프

2) Map객체의 Choropleth()

- Choropleth를 활용하여 GeoJson 데이터와 결합
- Choropleth : 행정구역별로 다른 색상을 표현
	보통 folium에 layer로 얹게 됨

- 사용 인수
	geo_data : 지도 파일 경로와 파일명
	data : 지도에 표현되어야 할 값 변수
	columns = [key로 사용할 data, 실제 data의 필드명]
	key_on : 지도 경계파일인 json에서 사용할 키 값
		 지도 Data는 표준 형식으로 만들어 져야 함
		반드시 feature.로 시작
		feature(키워드).json에서 나타나키 필드명

- 단계구분도를 map에 표시하는 함수
     folium.LayerControl().add_to(map)

3) 단계구분도 작성 단계

단계1. Map()객체 생성
 m = folium.Map(location = (37.566585446882, 126.978203640984),
                zoom_start=8)

단계2. GeoJson() 객체로 경계선 Map()객체에 붙이기
 folium.GeoJson(geo_gg).add_to(m)

단계3. Choropleth() 객체 생성 후 Map()객체에 붙이기

(방법1) geojson의 properties.name 속성과 데이터프레임의 인덱스를 기준으로 사용할 경우
 folium.Choropleth(geo_data=geo_gg,
                   data=gg_pop[2007],
                   columns=[gg_pop.index, gg_pop[2007]],
                   key_on='feature.properties.name',
                   fill_color='YlGn',
                   fill_opacity=0.7,
                   line_opacity=0.3,
                   legend_name='Gyeonggi population in 2017',
                   threshold_scale=[10000, 100000, 300000, 500000, 700000]
                ).add_to(m)


(방법2) geojson의 properties.name 속성과 데이터프레임의 한 컬럼을 기준으로 사용할 경우

 folium.Choropleth(geo_data=geo_gg,
                   data=gg_pop,
                   columns=['구분', 2007],
                   key_on='feature.properties.name',
                   fill_color='YlGn',
                   fill_opacity=0.7,
                   line_opacity=0.3,
                   legend_name='Gyeonggi population in 2007',
                   threshold_scale=[10000, 100000, 300000, 500000, 700000]
                ).add_to(m)
