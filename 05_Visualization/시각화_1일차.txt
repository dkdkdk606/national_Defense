#1. 데이터 시각화 개요
1. 데이터 시각화
1) 장점 
   많은 양의 데이터 시각적으로 요약
   더 정확한 데이터 분석 결과 도출
2) 기능
   설명, 탐색, 표현
3) 목적
   정보전달, 설득
4) 방법
  데이터 변수의 수, 종류, 분석목적에 따라 시각화 방법이 달라짐
  => 관계, 비교, 분포, 추세, 지리(공간)

2. 시각화의 필요성
 기술통계량의 결과가 동일하더라도 데이터의 분포가 매우 다를 수 있으므로
 시각화 방법을 함께 병행해야 함

3. 파이썬 기반 시각화 라이브러리들 
- matplotlib
- seaborn
- folium
- plotly
판다스 df.plot(kind=' ' ) 

4. 시각화 주의점
- 데이터 유형, 변수의 수, 목적에 맞는 시각화 플롯 사용
- 자료의 스케일, 비교 기준 표준화 사용하여 정보전달하도록 표현
- 너무 많은 잉크 사용자제
- 단순하고 간결하게 그러나, 데이터 정보를 왜곡하지 않도록 정확한 표현 사용

- 막대그래프는 값의 크기순으로 정렬하여 표현하면 비교하기에 좋음
- 파이차트의 경우 범주의 수가 6개 이상 많은 경우 비교하기 어려우므로, 막대그래프를 사용
- 파이차트는 각 범주별 빈도(비율)이 비슷한 경우 비교가 어려움
- 산점도 그릴때 x,y 종횡비를 데이터의 분포에 맞게 그리지 않는 경우 데이터 왜곡이 발생할 수 있음

3. 그림영역을 분할해서 플롯을 여러개 그리기
① subplot()
- subplot 하나씩 단순하게 붙이기
- 코드방식 : subplot을 하나씩 수동 지정
- 접근방식 : 번호로 직접 접근(plt.subplot(1,2,1)
- 반환 값 : 단일 Axes Subplot 객체
- 코드 구조 : 반복문 없이 단순한 코드지만 중복 많음
- 레이아웃 유연성 : 낮음
- 권장 사용 : 아주 단순한 1xN 또는 N행의 그래프
- 예시 코드 : plt.subplot(2,1,1)

② subplots()
- 반복적인 플롯 그리기
- 코드방식 :subplot을 배열로 일괄 생성
- 접근방식 : 배열의 인덱싱(axes[0,1], axes[1], axes[0][1])
- 반환 값 : (Figure, Axes) 튜플(Axes 배열 또는 객체 배열)
- 코드 구조 : 반복문 활용 가능. 배열 인덱싱 필요
- 레이아웃 유연성 : 중간(격자형만 가능)
- 권장 사용 : 다수 subplot을 일정한 행렬 형태로 반복하여 그릴 때
- 예시 코드 : fig, axes = plt.subplots(2,2)

③ subplot_mosaic()
- 이름으로 구역 구분, 복잡한 배치
- 코드방식 : 문자열/딕셔너리 기반으로 유연하게 레이아웃 구성
- 접근방식: 이름(label)으로 접근(ax['A'],ax['B'])
- 반환 값 : (Figure, dict[str, Axes]) 형태로 반환|
- 코드 구조 : 레이아웃 정의가 직관적이고 가독성 좋음. 반복문도 가능
- 레이아웃 유연성 : 매우 높음(불균형, 중첩, 특정 영역 확대 등 자유롭게 설정 가능)
- 권장 사용 : 복잡한 레이아웃, 대시보드 구성, 이름 기반으로 명확히 구분할 때
- 예시 코드 : fig, axes = plt.subplot_mosaic([['A','B'],['C','B']]))

9. 파이차트
- 범주형 데이터의 빈도(비율)을 비교하기 위해 사용하는 차트
- 원의 형태를 유지할 수 있도록 다음 명령을 실행해야 함

1) 형식
  matplotlib.pyplot.pie(x, explode=None, labels=None, colors=None, autopct=None,  startangle=0, radius=1, ...)

2) 인수들을 이용한 파이차트 표현
- startangle=0 : 파이차트는 3시 기준(0도)으로 시계반시계 방향으로 범주 데이터 표시함, 각도로 입력(0~360)
- radius=0.8 : 파이차트 반지름 길이. 기본값은 1
- explode=[0.2, 0,0,0] : 값을 0이상 준 데이터 조각(부채꼴)은 파이차트 밖으로 떨어져 그려짐(강조)
- autopct='%.2f%%' : 데이터 값을 퍼센트로 표시
- colors=['yellow','skyblue','coral','gold'] : 범주 별로 다른 색상 지정

plt.pie(size, labels=labels, startangle=90, radius=0.8,
        explode=[0.2, 0,0,0], autopct='%.2f%%',
        colors=['yellow','skyblue','coral','gold'])


10. 영역 차트
- 각 열(컬럼)의 데이터를 선그래프로 구현하되, 선그래프와 x축 사이의 공간에 색을 채움
- 시각적으로 강조(비교)하거나 특정 조건에 따라 색을 바꿀 때 유용
- plot()함수와 fill_between(), fill_betweenx() 함수를 사용

1) 함수 형식
  matplotlib.pyplot.fill_between(x, y1, y2=0, where=None, interpolate=False, step=None, *, data=None, **kwargs)
  matplotlib.pyplot.fill_betweenx(y, x1, x2=0, where=None, step=None, interpolate=False, *, data=None, **kwargs)

2) x축과 y의 값사이 영역 채우기
예. 
  x = [1, 2, 3, 4, 5]
  y = [1, 4, 2, 5, 3]
  plt.plot(x, y, color='blue')  # 경계선
  plt.fill_between(x, y, color='skyblue', alpha=0.5)   

3) 두 선 사이 영역 채우기
예.
  x = [1, 2, 3, 4, 5]
  y1 = [1, 4, 2, 5, 3]
  y2 = [2, 3, 1, 4, 2]
  plt.plot(x, y1, color='blue', label='y1')
  plt.plot(x, y2, color='darkblue', label='y2')
  plt.fill_between(x, y1, y2, color='skyblue', alpha=0.5)

4) 누적 영역 그래프 : stackplot()
- 여러 영역을 동시에 표시
- 형식 :
  matplotlib.pyplot.stackplot(x, *args, labels=(), colors=None, hatch=None, baseline='zero', data=None, **kwargs)

5) 기준선을 중심으로 음/양수 영역 색 다르게 표현

예.
  plt.fill_between(x, y, 0, where=(y >= 0), interpolate=True,
                 color='lightgreen', alpha=0.6, label='Positive Area')
  plt.fill_between(x, y, 0, where=(y < 0), interpolate=True, 
                 color='salmon', alpha=0.6, label='Negative Area')
