2. 모집단과 표본

(표본)통계량(statistic) : 표본의 특성

기술통계 : 요약.기술(통계량/시각화)
추론통계 : 추정/가설검정
=> 데이터의 분포
확률적 분포
확률정의 : 
	객관적 확률
	1) 수학적(고전적)확률  : 관심사건의 빈도/전체빈도   	P(A) = n(A)/N
	2) 경험적 확률 :  P(A) = lim(n->)n(A)/N

	주관적확률
	공리적해석 :
		1) 0<=P(A) <=1
		2) p(S) = 1
		3) A와 B는 상호배반 : P(AUB) = P(A) + P(B)

확률의 특성
	P(AUB) = P(A) + P(B) - P(A∩B)
	P(A의 여사건) = 1-P(A)

상호배반 : P(A1UA2 ...UAn) = P(A1) + P(A2) + ... + P(An)

조건부확률 : P(B|A) = P(A∩B)/P(A)  (축소된 표본공간)
두 사건이 독립 : P(B|A) = P(B)   P(A|B) = P(A) 
		P(A∩B) = P(A)P(B)

확률의  합법칙
	임의 두 사건 A, B에 대하여 P(AUB) = P(A) + P(B) - P(A∩B)
	두 사건이 상호배반이면 P(AUB) = P(A) + P(B)
	P(A∩B) = 0

확률의 곱법칙
	두 사건의 교집합 확률이 
		P(A∩B) = P(A)P(B|A) 또는 P(A∩B) = P(B)P(A|B)
	두 사건이 독립이면
		P(A∩B) = P(A)P(B)

상호배반적 -> 두 사건이 동시에 발생할 수 없음
상호독립적 -> 한 사건이 다른 사건의 확률에 변화를 주지 못함

표본공간(sample space)  : 가능한 모든 결과의 모임

분할 : 표본공간을 분할하는 사건들
	S = B1UB2U..UBn
전확률의 정리
	P(A) = ΣP(A∩Bi)=  ΣP(Bi)P(A|Bi)

베이즈정리 : 사전확률이 새로운 사건의 정보가 주어지므로 개선되는 것
	사후확률

3. 확률변수와 확률분포

확률변수 : 실험이나 관찰의 결과 값을 1:1 실수로 대응시키는 함수
	일정한 확률로 나타나는 사건에 대해 숫자를 부여한 변수

확률분포 : 확률변수가 취할 수 있는 모든 값에 대해 각각의 확률을 대응시킨 것
	확률변수와 각 확률변수가 갖는 확률값을 대응시킨 식, 표, 그래프

이산형확률변수 / 연속형확률변수

이산형확률분포함수 : probability mass function, pmf
 - 베르누이 / 이항분포 / 포아송분포 / 균일분포

연속형확률분포함수 : probability density function, pdf
  - 정규분포 / 카이제곱분포 / F분포 / t분포 /

4. 확률분포의 기대값과 분산

확률분포의 평균 : 기대값(expected value) E(X)=μ
분산 Var(X)=σ^2

E(aX+b) = aE(X) + b
Var(aX+b) = a^2Var(X)

5. 이산형 확률분포
이산형확률변수 -> 이산형확률분포

1) 베르누이 시행 : 성공확률 
  성공 /실패 두가지 결과만 있는 경우

2) 이항분포
 n번 베르누이 시행을 한 분포 -> 이항분포
 독립시행

- X~B(n, p)  X=0,1,..,n
  P(X) = nCx p^x(1-p)^(n-x)    X = 0,1,2,...,n
          0 		       else 
- 기대값 E(X) = np
- 분산V(X)=np(1-p)

3) 포아송분포
 단위길이, 단위시간, 단위면적 등 주어진 단위동안 발생한 사건의 수의 분포
- X~Poisson(λ)  X= 0,1,..
- 기대값 E(X) = λ
- 분산V(X) = λ

-------------------------------------

6. 연속형확률분포
연속형확률변수 -> 연속형확률분포
1) 정규분포
 - 좌우대칭, 평균과 분산
 -  X~N(mu, sigma) 
 -  Z = (X-mu)/sigma   Z~N(0,1)

2) t분포 
 - 소표본, student's t (고셋)
 - X~t(df=n-1)   n이 커질수록 정규분포로 근사

3) F분포
 - 분산의 비를 검정
   X~F(df1,df2)

4)카이제곱분포
 - X~Chi(df)
 - 카이제곱검정

5) 지수분포
  - 어떤 사건이 발생할때 까지 걸리는 시간의 분포

- scipy.stats 모듈에서 제공하는 확률분포API
  norm().pdf()  , ppf(), cdf(), interval(), mean(), var()
  t()
  binom()
