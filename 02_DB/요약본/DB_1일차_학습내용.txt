1. 데이터베이스 개요
1) 데이터베이스 개념 ISOS
 - 여러 사람이 공유하여 사용할 목적으로 체계화해 통합, 관리하는 데이터의 집합
 - 여러 응용 시스템들의 통합된 정보들을 저장하여 운영할 수 있는 공용 데이터들의 묶음
 통합(Integrated) + 저장(Stored) + 운영(Operational) + 공용(Shared)

2) DBMS : 데이터베이스 관리 시스템
   Oracle, MySQL, DB2, SQL Server, Maria DB 등

3) DBMS 발전 과정
   수기(종이) -> 파일시스템 -> 데이터베이스시스템
   -> 웹데이터베이스 -> 분산데이터베이스

4) 데이터베이스의 특징 R1C3
   - 공유, 무결성, 중복 최소화, 데이터 독립성, 안정성, 보안
   - 데이터 추상화, 다양한 뷰 제공, 응용프로그램 제작 및 수정 용이
   - 쉬운 데이터 접근, 데이터 표준화 가능, 최신 데이터 유지
   - 단점 : 전문인력 필요, 복잡한 시스템, 데이터 백업&복구 어려움
* 실시간 접근성(Real Time Accessibility) : R
  지속적인 변화(Continuous Evolution)
  동시 공유(Concurrent Sharing)
  내용에 의한 참조(Content Reference)

5) DBMS 기능
   - 데이터 정의
   - 데이터 조작
   - 데이터 제어

6) DBMS 분류
  - 계층형, 망형, 객체형, 관계형, NoSQL

7) DBMS에서 사용하는 언어 : 질의어(Structured Query Language)
 - 국제표준SQL : ANSI SQL
 - Oracle : PL/SQL
 - SQL Server : T-SQL
 - MySQL : SQL

4. 데이터베이스 설계
- 사용자의 요구를 분석하여
- 컴퓨터에 저장할 수 있는 데이터베이스의 구조에 맞게 변경한 후
- 특정 DBMS로 구현하여
- 사용자들이 사용할 수 있게 하는 것

1) 설계 단계
요구사항 분석 → 개념적 데이터 설계 → 논리적 데이터 설계 → 물리적 데이터 설계 -> 구현

2) 데이터 모델링
- 현실 세계 관점의 사물/작업 등을 DBMS의 DB로 구현하는 과정
- 현실 세계의 복잡한 개념을 단순화/추상화하여 DB화하는 기법
- 현실에 존재하는 개체의 구성 요소가 가지는 값을 컴퓨터 세계에 표현하기 위한 현실 세계와 컴퓨터 세계 사이의 변환 과정

   개념적 데이터 설계(모델링) → 논리적 데이터 설계 → 물리적 데이터 설계

 개념적 모델링: 요구사항분석 토대로 개체(Entity)-관계(Relation)를 찾아냄, ERD활용(개체-관계의 속성들, 제약조건들을 규명)
 논리적 모델링 : ER기반으로 DBMS에 맞게 매핑
     정규화, 데이터 표준화 수행
 물리적 모델링 : 논리적 모델을 실제 컴퓨터의 저장 장치에 저장하기 위한 물리적 구조를 정의(자료형, 크기)

4) 테이블 생성 및 제약 조건 설정
CREATE TABLE 테이블명 (
  열이름 데이터타입
  [NOT NULL] [UNIQUE] [DEFAULT 기본값] [CHECK 체크조건]
 [, PRIMARY KEY 열이름]
 [, FOREIGN KEY 열이름 REFERENCES 테이블명(열이름)]
 [, CONSTRAINT명] CHECK(조건식)]
);

creare table 테이블명 (
	열이름1 데이터타입 [제약조건],
    열이름2 데이터타입 [제약조건],
    열이름3 데이터타입 [제약조건],
    열이름4 데이터타입 [제약조건],
    ...,
    열이름n 데이터타입 [제약조건]
    constraint 제약조건명 primary key(컬럼이름,),
    constraint 제약조건명 foreign key 컬럼이름 reference 테이블명(컬럼이름),
    
);
*기본키를 복합키를 사용할 경우 반드시 constraint 문에서 정의할 것

[제약조건]
not null	: 빈값 허용하지 않음
primary key	: 기본키 설정
foreign key 컬럼이름 references 테이블명(컬럼이름) : 외래키 설정
unique 		: 중복값 허용하지 않음
default 기본값 : 기본값 설정
check 체크조건	: 특정 내용의 제약조건(값 범위 등)
on delete 또는 on update : 참조되는 테이블의 행 삭제/갱신 시 옵션
