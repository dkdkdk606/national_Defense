#1. 데이터 재구조화(reshaping)

1. pivoting : 
 1) df.pivot(), pd.pivot(df, index=, columns=, values=)
    row가 unique한 경우 stacked format(long) -> record format(wide)
 2) df.pivot_tables(index=, columns=, values=, aggfunc=)

2. stack & unstack
 1) pd.stack(level=, dropna) 
     인덱스 레벨 증가: long format
     컬럼 레벨 해제

 2) pd.unstack(level=, )
    인덱스 레벨 해제 : 컬럼 레벨 증가 : wide format

3. melt
  컬럼들이 변수의 값으로 변경 : wide-> long
  df.melt(id_vars=, value_vars= , var_name=,  value_name=   )

4. wide_to_long
   컬럼이름들이 중복된 규칙을 가지고 있음
   score1, score2,  => score, nth
   A2020, A2022, B2020, B2022  => A, B, year
   A_2020, B_2020, A_2022, B_2022
   A_one, B_one, A_two, B_two
   df.wide_to_long(stubnames= , i=[ ], j=, sep= , suffix= )

5. crosstab
   교차표(빈도분포표) 생성
   pd.crosstab(index= , columns= ,   normalize=, margins=) => 빈도(비율)
   pd.crosstab(index= , columns= ,  values=,  aggfunc= ) => aggfunc 함수적용

6. explode
   컬럼 내에 리스트와 같은 데이터를 값으로 갖는 구조에 대해서
   리스트 요소들을 하나씩 갖도록 

   A = [ [1,2,3 ], [], ( ), ' ', 3]

[재구조화 정리]
- pivot : 돌려서 가로로 펼치기
- pivot_table : pivot + 집계
- crosstab : 교차빈도표 생성
- stack : 열을 아래로 쌓기
- unstack : 행인덱스를 옆으로 펼치기
- melt : 녹여서 세로로 모으기
- wide_to_long : 넓은 반복 컬럼을 긴 구조로 바꾸기
- explode : 한 셀을 터뜨려 여러 행으로 만들기

|함수			|방향			|주요 목적				| 집계 기능| 중복 허용|주요 용도|
-----------------------------------------------------------------------------------------------------------------
| pivot        	| long → wide     | 행 값을 컬럼으로 변환   	 | 없음    | 불가    | 구조 재배열        |
| pivot_table  	| long → wide     | pivot + 집계     		 | 가능    | 가능    | 요약 통계표        |
| crosstab     	| long → wide     | 교차 빈도표 생성      		 | 가능    | 가능    | 범주형 빈도 분석 |
| melt         	| wide → long     | 여러 컬럼을 행으로 변환 	 | 없음    | 가능    | tidy data    	  |
| stack        	| columns → index | 컬럼 레벨을 인덱스로 이동 | 없음    | 가능    | MultiIndex 처리  |
| unstack      	| index → columns | 인덱스 레벨을 컬럼으로 이동 | 없음 | 가능    | 그룹 결과 재구성 |
| explode      	| list → rows   	| 리스트 셀을 행으로 분해  	 | 없음    | 가능    | 다중값 컬럼 처리 |
| wide_to_long 	| wide → long     | 패턴 컬럼명을 long 변환	 | 없음    | 가능    | 반복 측정 데이터 |

참고. df.assign(컬럼) : 새로운 컬럼 추가

#2. 그룹별 분석

1. 데이터 그룹화 단계(패턴)
 1단계 : 분할(split) -> groupby()메서드로
 2단계 : 적용(apply) 
	집계를 위한 내장함수 sum(), count(), describe(), boxplot(),...
	집계를 위한 사용자정의함수(func) 적용 : agg(func), apply(func)
	변형 : transform()
	추출 : filter()
 3단계 : 결합(combine 또는 aggregate)

2. pd.groupby(by=['',...], axis=0, level=0, as_index=True, 
	     dropna=True, ... )
 - GroupBy 클래스 객체로 그룹별로 그룹이름과 데이터를 튜플로 반환
 - 속성들 : 
	groups: 그룹정보 {그룹이름1:[인덱스,...], 그룹이름2: [...]}
	ngroups : 그룹 수
	indices : 그룹정보 {그룹이름1: np.array[인덱스,...],
			  그룹이름2: np.array[인덱스,...],...}
 - 메서드들
	get_group(그룹이름) : 그룹데이터
	size() : 그룹별 행개수
	count() : 그룹별 컬럼들의 아이템 개수(결측치 제외)
 	집계관련 내장함수들
	agg(), aggregate(), apply(), transform(), filter()

3. 그룹화
 1) 단일 컬럼으로 그룹화
 2) 다중 컬럼으로 그룹화
 3) 인덱스로 그룹화
 4) mapping 데이터(딕셔너리) 또는 시리즈로 그룹화
 5) 함수로 그룹화


4. 집계
 1) 내장함수로 집계 :그룹별객체.내장함수
 2) 사용자정의함수로 집계 : agg(), apply() 사용
    그룹별객체.agg(함수명, *args, **kwargs) : 수치형스칼라값을 반환하는 함수만 적용
    그룹별객체.apply(함수명, *args, **kwargs) : 다양한 결과를 반환하는 함수 모두 적용

5. 변형(transform)
  그룹별객체.transform()

6. 추출(filter)
  그룹별객체.filter()
